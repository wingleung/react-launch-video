# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful, assume good intent, keep criticism about the work rather than the person and accept that
maintainers decide what ships. Harassment of any kind is not welcome here.

Report unacceptable behaviour through this repository's
[private vulnerability reporting form](https://github.com/wingleung/react-launch-video/security/advisories/new), which
only maintainers can read. GitHub has no direct messages, so that form is the private channel here, as it is for
security reports (see [SECURITY.md](SECURITY.md)).

Reports are handled confidentially, and maintainers may remove comments, commits, issues or contributors that break
these terms.
