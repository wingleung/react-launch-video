# Relay

Relay is a small issue tracker for product teams. This copy is a test fixture for the product-reel plugin: a real,
runnable React app with the kinds of details a reel has to handle (a clock-based greeting, CSS transitions, a debounced
search).

## Features

- **Inbox**: every open issue, grouped by status.
- **Focus mode**: a setting that shows only the issues assigned to your team.
- **Quick find**: press Ctrl K to search issues and run actions from the keyboard.

Run it with `npm install` and `npm run dev`.
